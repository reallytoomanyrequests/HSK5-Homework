## 0. 원칙

1. **형식은 공식 样题와 교재 모의고사를 그대로 따른다.** 문항 수, 턴 수, 지문 길이, 질문 문구("问：…"), 보기 형식, 지시문 원문.
2. **내용은 기출 패턴 안에서 새로 쓴다.** 기출·교재 문항을 그대로 쓰지 않는다. 토픽·전개 구조·오답 설계 방식·표현은 패턴을 따른다.
3. **어휘는 5급 누적 범위(3,600어).** `tools/vocab_check.py` 기준 5급 초과 단어 3% 이하. 고유명사(인명·지명)와 지문 이해에 필요한 전문어 1~2개는 허용하되 해설에 뜻을 단다.
4. **난이도는 "5급 중간".** 2.0 기출 중앙값 수준. 성어는 지문 300자당 1개 이하, 대화 20편당 2~3개.
5. **매일 전 파트를 조금씩.** 로테이션은 `plan.json`. 수업일에는 쓰기 제외.
6. **자가검수 후 올린다.** 어휘 검사 → JSON 스키마 검사 → 음성 ASR 대조(90% 이상) → 정답 유일성 확인(보기 중 정답이 둘로 해석되지 않는지 재검토).

## 2. 듣기 1부분 (대화)

### 2-1. 형식
- **1~10번**: 男/女 2턴씩 총 4턴, 60~90자. 질문 1개 "问：…？". 첫 화자는 문항마다 남녀 교대(홀수 女, 짝수 男).
- **11~19번**: 3턴씩 총 6턴, 150~200자. 질문 2개(가끔 3개). 정보 전달형(용어 설명, 방법 안내, 인터뷰)이 많다.
- 음성: 대화 → 0.6초 → "问：…" → 답 고르는 시간 10초(긴 대화는 질문마다 10초). 질문은 여성 내레이터.
- 보기 4개는 **길이·품사·구조 통일**. 명사(2~4자) / 동사구(4~6자, 样题 "现场排队购票" 형) / 짧은 절(5~9자) / 태도어(2~4자).

### 2-2. 질문 유형 배합 (2.0 기출 80문항 집계 기준, 하루 5~6문항에 적용)
| 유형 | 비율 | 대표 문구 |
|---|---|---|
| 종합 세부 | 20% | 关于男的/女的，可以知道什么？ / 根据对话，下列哪项正确？ / 关于那家公司，可以知道什么？ |
| 의도·태도·관점 | 14% | 男的是什么意思？ / 女的是什么态度？ / 女的主要是什么观点？ |
| 행동·계획·제안 | 15% | 男的接下来要做什么？ / 女的建议怎么做？ / 男的想请女的做什么？ / 他们打算怎么办？ |
| 특정 명사·인물 | 15% | 女的忘了拿什么？ / 谁出差了？ / 男的对什么印象深刻？ / 男的是怎么知道的？ |
| 이유 | 12% | 女的为什么来晚了？ / 会议为什么推迟了？ / 男的为什么要感谢女的？ |
| 평가 | 10% | 男的觉得那个方案怎么样？ / 女的乒乓球打得怎么样？ |
| 장소·시간 | 8% | 他们最可能在哪儿？ / 对话最可能发生在什么时候？ |
| 직업·관계·상태 | 6% | 男的最可能是做什么的？ / 他们最可能是什么关系？ / 女的怎么了？ |

하루 5문항이면 "종합 1 / 의도 1 / 행동 1 / 명사 또는 이유 1 / 평가·장소·관계 중 1". 교재 유형(장소·직업 등)을 그 주 집중 유형으로 두되, 한 세트 전부를 그 유형으로 채우지 않는다.

### 2-3. 오답 설계 (한 문항에 2가지 이상 적용)
1. 대화에 나온 단어를 그대로 쓰되 관계를 바꾼 보기. 정답은 **바꿔 말하기**(落在出租车上 → 东西丢了, 打折 → 优惠, 粗心 → 马虎).
2. 주체 바꾸기(남자 계획 → 여자 보기).
3. 첫 턴 제안이 둘째 턴에서 수정·거절되면 첫 제안을 오답으로.
4. 숫자·시간 두 개 중 바뀐 쪽이 정답.
5. 반어·완곡 표현 직역 오답(这还用说吗 → 当然 / 那怎么好意思 / 看情况吧 / 恐怕有点儿…).
6. 명백한 무관 보기 1개.

### 2-4. 장면 배합 (주간)
직장·업무 25% / 건강·운동 10% / 소비·서비스 12% / 가정·주거 10% / 학업 8% / 취미·문화 10% / 여행·교통 8% / 디지털 생활(앱 예약·소프트웨어) 8% / 기타(금융·사회·환경) 9%. 3.0은 "앱으로 예약", "용어 설명(留白)" 같은 **디지털·문화 상식 설명 장면**을 꼭 섞는다.

### 2-5. 5급다운 장치
把/被 문, 결과·방향·가능 보어(来得及·受不了·坚持下去), 连…都…, 어기부사(倒·未必·难怪·索性·简直·反正·居然·毕竟·不妨·恐怕), 격식어 정답(委婉谢绝·表示感谢·持怀疑态度·不以为然).

## 3. 듣기 2부분 (단문)

- 길이 **200~300자**(음성 50~80초, 분당 220~250자). 질문 2~3개, 질문은 음성 + 10초 간격.
- 장르 배합: **이야기·우화·역사 일화 55% / 설명문 30% / 논설문 15%.** 3.0 样题는 역사 일화(苏洵 藏书) 3문항.
- 문항 배합(지문당 3): **세부 2 + 주제·교훈 1.** 이야기·논설은 마지막 문항을 "这段话主要想告诉我们什么？" 류로. 질문 순서는 지문 전개 순.
- 질문 문구: 세부 「X为什么…？」「X做了什么？」「X后来怎么样了？」; 종합 「关于X，可以知道什么？」; 주제 「这段话主要谈的是什么？」「这个故事主要想告诉我们什么道理？」; 어휘 「"X"最可能是什么意思？」.
- 첫 문장 패턴: 이야기 「从前，有一个…」「一天，…」「宋代有个叫…的人」; 설명 「…是指…」「有一项调查显示，…」「心理学上有一个…效应」; 논설 통념 → 其实/然而 → 所以.
- 결말 패턴: 이야기 「这个故事告诉我们，…」「可见，…」「人生也是如此，…」(교훈은 추상 명제로); 설명 「因此，…」「专家建议，…」.
- 교재 집중 유형 순서: 1주 이야기·실용문 → 2주 설명문 → 3주 논설문 → 이후 혼합.

## 4. 독해 1부분 (빈칸)

- 하루 지문 1편 **200~280자**, 빈칸 3~4개. **절 빈칸 1개 + 어휘 빈칸 2~3개.**
- 어휘 빈칸 품사 비율(기출 60칸): 동사 42% / 명사 15% / 형용사 15% / 부사 7% / 접속·개사 2%. 양사는 내지 않는다.
- 보기 4개는 **같은 품사·같은 음절 수**, 의미 영역이 겹치거나 한 글자를 공유(制定/制作/建立/形成, 表现/表达/表明). 정답은 **고정 搭配**로 결정(满足需求·提高水平·承担责任·承受压力·实现目标·养成习惯·克服困难·发挥作用·保持距离·制定计划).
- 절 빈칸: 보기 4개 길이 6~12자, 같은 화제어 사용. 정답은 주어 연속성·지시어·접속사 짝·긍부정 방향으로 결정. 오답은 짝 안 맞는 접속사, 반대 방향 결과, 지시 대상 없는 这/其.
- 혼동 쌍 풀: 满足/满意, 提高/增加, 持续/连续/陆续, 反应/反映, 包含/包括, 临时/暂时, 权利/权力, 掌握/把握, 保持/维持, 实现/达到/完成, 承受/承担/担任, 深刻/激烈/强烈/彻底, 广泛/普遍/普通, 始终/陆续/未必/急忙, 从而/进而, 至于/以及/何况, 办法/方式/方法.

## 5. 독해 2부분 (문단 배열)

- 하루 1세트: **5문단(A~E), 전체 300~400자**, 문단당 2~3문장. 答案은 46~50 각 자리에 문단 기호.
- 장르: 이야기(역사 인물·일화) 또는 설명·논설(현상 → 원인 → 영향 → 대책). 주간 2세트면 하나씩.
- 유일 정답 보장 장치: ① 첫 문단에만 인물 전체 이름·배경 ② 이후 他/这位/这个孩子 지시 ③ 시간어 사슬(小时候 → 后来 → 有一天 → 几天后 → 从此) ④ 중간 문단은 于是/没想到/可是/因此/这时로 시작, 결말 문단은 从此/就这样/原来 ⑤ 「为什么…呢？」 → 다음 문단 原来… 짝. 문단 교환이 가능하면 단서를 하나 더 넣는다.
- 앱 표기: passage에 A~E 문단을 제시하고 questions는 "①~⑤ 자리" 5문항, 보기 A~E.

## 6. 독해 3부분 (지문 독해)

- 하루 지문 1편 **400~500자**, 3~4단락, 문항 4개(또는 3개).
- 장르: 이야기·일화 45% / 인물 체험형 설명·문화 소개 35% / 논설·수필 20%. 3.0 样题는 외국인의 차 문화 체험 설명문.
- 문항 배합: **세부 2 + 어휘 의미 또는 종합 1 + 주제·제목·교훈 1.** 순서는 전개 순, 주제는 마지막.
- 질문 문구: 세부 「根据上文，X为什么…？」「X是如何…的？」「根据第N段，可以知道：」; 종합 「关于X，可以知道什么？」「根据上文，下列哪项正确？」; 어휘 「第N段中画线部分的意思最可能是：」「可以替换第N段中"X"的词语是：」; 주제 「上文主要想告诉我们：」「最适合做上文标题的是：」(보기 4~8자 명사구).
- 오답: 본문 어구 복사 + 주체·결과 바꾸기, 정도어 조작(可能 → 一定, 有些 → 所有), 시간 어긋남, 제목은 너무 넓음/좁음.
- 교재 집중 유형 순서: 육하원칙 → 세부사항 → 일치·불일치 → 중심내용 → 의미파악 (주 1유형, 다른 유형 1문항씩 섞음).

## 7. 쓰기

### 7-1. 1부분 看图写作 (71번)
- 지시문: 「根据下面四张图片，写一篇不少于100字的作文，讲述发生在[인물]和伙伴们身上的故事。」 인물명은 小李·李敏·王伟·李娜·小明 등 2~3자.
- 그림 4장은 시간순 기승전결. 주인공 감정이 드러나는 장면. 두 유형: ① 목표 달성·선행(채소 수확, 대회 협력 → 1등, 봉사, 등산 정상) ② 예상 못한 문제 → 해결(강아지 분실 → 찾음, 길 잃음 → 지도, 합주 실패 → 성공, 여권 두고 옴).
- 그림 제작: 선화 삽화 4장(`w1_1.png`~`w1_4.png`), 각 장면 설명을 answers.json `scene` 필드에 한국어로도 기록.
- 모범답안 120~150자 틀: 一天/上个周末，[인물]和伙伴们在[장소]… → 突然/他们先…然后… → 这时/没想到…，[감정] → 最后…，大家都…。(通过这件事，…)
- 체크리스트(points): 4장 모두 언급 / 시간·장소·인물로 시작 / 감정 표현 1개 이상 / 100자 이상 / 결과 또는 깨달음 한 문장.

### 7-2. 2부분 话题作文 (72번)
- 题干 구조: **명제(1~2문장) + 「请你写一篇不少于200字的作文，」+ 요구 2개**(경험+느낌 / 견해+이유 / 두 대상 비교 후 선택 / 장점+단점). 样题: 「尝试可能会成功，也可能会失败，但不去试一试就永远不会成功。请写一篇不少于200字的作文，分享你曾经做过的一次尝试，以及你尝试后的感受。」
- 유형 ① 경험·인물: 我有过这样一次经历，那是… → 首先/接着/最后 또는 一方面/另一方面 → 这次经历让我明白了，…。 ② 견해: 每个人对…都有不同的看法。在我看来，… → 一方面…另一方面…(此外) → 总的来说，我认为…。
- 모범답안 220~260자, 쉬운 어휘로 문법 오류 없이. 보조 표현: 这对我来说是个不小的挑战，但最终… / 只有…，才能… / 既有优点也有不足 / 随着…的发展 / 不管遇到什么困难，只要…，就一定能….
- 주제 풀(교재 + 기출 + 大纲 话题, 2주 내 중복 금지): 도전 극복 경험 / 남을 도운 경험 / 가장 잊지 못할 하루 / 여행이 준 영향 / 노력 끝의 성공 / 훌륭한 동료·스승 / 인생에서 가장 중요한 것 / 건강 유지 방법 / 失败是成功之母 / 나의 장점 / 전자책 vs 종이책 / 시간이 충분하다면 / 개인 능력 vs 팀워크 / 환경 보호 작은 실천 / 언어 학습 방법 / 직업 선택 / 온라인 쇼핑 장단점 / 스마트폰 의존 / 소비 습관 / 세대 소통 / 전통문화 체험 / 반려동물 / 도시 vs 농촌 / 독서의 의미 / 자원봉사 / 성공의 정의 / 스트레스 해소 / 인공지능과 생활.
- 체크리스트: 200자 이상 / 요구 조건 2개 모두 충족 / 서론·본론·결론 표지어 / 구체적 사례 1개 / 결론에 입장 재진술.

## 8. 말하기

### 8-1. 1부분 听后复述 (1~2번) — 하루 2문항
- 지문 **30~40초 = 90~130자**, 1회 청취, 준비 없이 1분 30초 답변. 여성 내레이터.
- 지문 유형: ① 일화·교훈 이야기(귀향 창업, 노래 대회, 낙엽 치우는 소년) ② 의견 주장(독서·교육·성공) ③ 설명(低头族, 건강 습관). 인물 2명 이하, 사건 3단계(상황 → 전환 → 결과), 숫자·고유명사 최소.
- 모범 답변 틀(100~130자): **刚才我听到的是关于[화제/인물]的文章。下面我来复述具体内容。**[핵심 내용, 직접화법은 간접화법으로]**以上是我所听到的关于[화제/인물]的文章。**
- 체크리스트: 시작·끝 고정문장 / 인물·사건·결과 3요소 / 핵심 동사·접속사(于是·结果·因此) 재활용 / 직접화법 → 간접화법.

### 8-2. 2부분 看图说话 (3번)
- 사진 3장(`s2_1.png`~`s2_3.png`), 준비 3분, 답변 2분. 유형 ① 시간 흐름(집 구하기 → 계약 → 입주, 짐 싸기 → 공항 → 비행기) ② 문제 → 해결(자전거 넘어짐 → 재도전, 요리 실패 → 성공, 차 고장 → 보험사 → 견인차).
- 모범 답변 틀(150~180자): 上个周末，小王和…在[장소]…，[상황/문제]，[감정]。 → 这时候/于是/但是他没有放弃，… → 经过努力，…终于…。虽然…，但是…，他感到非常高兴和幸福/有成就感。
- 체크리스트: 주인공 이름 정하기 / 시간·장소로 시작 / 3장 모두 언급 / 감정 변화 / 2분 분량(150자 이상).

### 8-3. 3부분 回答问题 (4~5번) — 하루 2문항
- 질문 문제지 제시(음성 없음), 준비 3분 30초, 답변 2분 30초. 세 유형 ① 의견·경험(你认为…有哪些影响？/ 你遇到过最大的困难是什么？) ② 찬반·선택(有人认为…，你是否同意？/ …哪个更重要？) ③ 상황 가정(如果/假如…，你会…？).
- 하루 2문항은 서로 다른 유형으로.
- 모범 답변 틀(200~250자): **我认为… / 我(不)同意这个观点 / 我觉得…更… / 如果…，我会…** → **第一/首先，…。具体来说/比如，…** → **第二/其次，…** → **第三/最后，…** → **综上所述/总而言之，…**.
- 질문 풀: 교재 6-3 목록 30여 개 + 大纲 话题 기반 신규(기술·환경·소비·직장·교육·전통·건강·도시). 2주 내 중복 금지.
- 체크리스트: 입장 한 문장 / 이유 2~3개 + 예시 / 마무리 재진술 / 2분 30초 분량.

## 9. 어휘·문법 규칙

- 어휘: `hsk30_lists.json` 1~5급(누적 약 3,600어) 안에서. `tools/vocab_check.py` 5급 초과 3% 이하. 6급 단어를 써야 하면 문맥으로 뜻이 드러나게 하고 해설에 뜻 기재. 독해 3부분 "어휘 의미" 문항은 6급어·성어를 의도적으로 1개 넣어도 된다.
- 쓰기 모범답안은 书写 한자 범위(1~5급 550자) 밖 글자를 가급적 피한다(학생이 손으로 못 쓰는 글자).
- 문법: `grammar_hsk5.txt`의 5급 항목(彼此·如此, 명량사 册·届·颗·批·束·副, 부사 过于·格外·居然·毕竟·反而, 개사 自从·朝·沿着·凭·据, 접속 以及·从而·可见·假如·总之, 四字格 A来A去·说A就A, 不得了·用不着 등)을 지문·대화에 하루 3~5개 자연스럽게 배치하고 해설에서 짚는다.
- 성어: 지문 300자당 1개 이하. 풀: 坚持不懈·半途而废·全力以赴·熟能生巧·实事求是·随机应变·恍然大悟·莫名其妙·迫不及待·理所当然·显而易见·潜移默化·一举两得·不知不觉·与众不同·日新月异. 속담: 活到老，学到老 / 失败是成功之母 / 一寸光阴一寸金 / 吃一堑，长一智.
- 접속 표지(해설에서 짚기): 然而·不过·却·反而 / 因此·于是·从而·之所以…是因为 / 只要…就·只有…才·除非…否则·无论…都·即使…也 / 不仅…而且·甚至·此外 / 与其…不如·宁可…也不 / 首先…其次…最后·总之·由此可见·综上所述.

## 10. 토픽 운영

- 토픽은 `syllabus_topics_hsk5.md`의 72개 话题에서 고른다. 하루 세트의 듣기·독해·쓰기·말하기 토픽은 서로 다르게, 한 주 안에서 범주(日常生活/教育/职场/自然环境/科技/当代社会/文化传统) 7개가 모두 한 번 이상 나오게.
- 기출 빈출 상위(직장·건강·교훈 이야기·역사 인물·학업·소비·인간관계·전통문화·자기계발·여행·예술·디지털·환경·경영·사회변화·동물·교육·주거·금융·독서)를 70%, 3.0 신규 话题(经营管理·科技产品·中国概况·经济现象·社会现象·文艺形式)를 30%.
- `homework/topics_used.json`에 회차별 토픽을 기록하고 2주 내 재사용 금지. 역사 인물은 중복 금지(苏洵·范仲淹은 样题에 쓰였으므로 제외).

## 11. 하루 세트 조립 절차 (자동 생성 세션용)

1. `plan.json`에서 오늘 요일의 로테이션, 현재 단계(by_type / mixed / mock), 수업일 여부 확인. `homework/` 폴더 목록과 `topics_used.json`으로 회차 번호·토픽 중복 확인.
2. 그 주의 집중 유형(§2~6)과 토픽을 정하고, 파트별 원고 작성: 듣기 대화(§2) → 단문(§3) → 독해 1·2·3(§4~6) → 쓰기(§7) → 말하기(§8). 각 문항에 정답·해설·근거 문장을 함께 쓴다.
3. 검사: `vocab_check.py --file set.json`, `--file answers.json` (3% 이하) → 질문 유형 배합 확인 → 보기 길이·품사 통일 → 정답 유일성 재독.
4. 음성: 듣기 1부분 + 2부분을 `listening1.mp3` 하나(또는 파트별 둘)로, 말하기 1부분 2문항을 `speaking1.mp3`로. `build_audio.py` → `asr_check.py` 90% 이상(미달 시 해당 문장 재생성).
5. 그림: 쓰기 1부분 4컷 / 말하기 2부분 3장은 선화 SVG → PNG(800px). 장면 설명은 answers.json에 기록.
6. `set.json`·`answers.json` 작성(`tools/README.md` 스키마), `homework/index.json`과 `topics_used.json` 갱신, 커밋·푸시. 커밋 메시지 "Day N (YYYY-MM-DD)".
7. 소요 시간 목표 25분 이내. 음성 생성 실패 시 엔진 B로 폴백하고 note에 표시.

## 12. 미확인·주의 사항

- 3.0 공식 口语 样题 원문은 미확보(교재 기술과 2차 자료 일치: 복述 2 / 사진 3장 1 / 질문 2, 약 23분). 지문 길이 30~40초는 교재 기준.
