## 2. 각 파트 표제·지시문 원문과 문항 형식

출처: 발췌본 p.29–35

**중요:** 이 문서의 听力·阅读 파트에는 「请选出正确答案」류의 한 줄 지시문이 **없음**. 표제 + 「示例」 라벨 + 문항만 수록. 지시문 원문은 미확인(실제 시험지의 지시문은 이 문서로 확인 불가). 写作 두 부분만 문제 지시문(=문제 자체)이 있음.

| 영역 | 표제 원문 | 示例 라벨 원문 | 형식(샘플에서 확인되는 범위) |
|---|---|---|---|
| 听力 第一部分 | 「第一部分（1-19 题）」 | 「示例（1-10 题）：」, 「示例（11-19 题）：」 | 1–10: 男/女 2턴 짧은 대화 → 질문 1개(「问：…」) → 보기 A–D. 11–19: 6턴 긴 대화 1편 → 질문 2개(11, 12) → 각 보기 A–D. 샘플은 각 그룹당 1편만 수록되어 모든 문항이 같은 형식인지는 미확인 |
| 听力 第二部分 | 「第二部分（20-35 题）」 | 「22-24.」 | 설명문/이야기 단문 1편(8문장, 약 230자) → 질문 3개(22–24) → 각 보기 A–D. 20–35 전체의 지문 수·지문당 문항 수는 미확인 |
| 阅读 第一部分 | 「第一部分（36-45 题）」 | 「示例：」 (42–45) | 선택식 빈칸 채우기(단어/구 선택). 지문에 빈칸은 「42 」처럼 숫자만 표기. 보기 A–D는 단어 또는 짧은 구(42번은 절 단위 「比起其他交通工具」 등). 「选词填空」 등 명칭은 문서에 없음 |
| 阅读 第二部分 | 「第二部分（46-55 题）」 | 「示例：」 (51–55) | 문단 순서 배열. A–E 5개 문단 → 51–55 빈칸에 순서대로 문단 기호 기입. 정답 표기 「正确答案：51．B 52．A 53．E 54．D 55．C → → → →」. 고정 첫 문단 여부·46–50의 형식은 미확인 |
| 阅读 第三部分 | 「第三部分（56-70 题）」 | 「示例：」 (63–66) | 장문 독해(4문단, 약 430자) → 4지선다 4문항(63–66). 밑줄 부분 의미 묻기(「第一段中画线部分的意思最可能是：」), 세부 내용, 「根据上文，下列哪项正确？」 유형 확인. 判断对错·填空 유형은 샘플에 없음 |
| 写作 第一部分 | 「第一部分」 (문항번호 없음) | 「示例：」 | 4컷 그림 보고 100자 이상 이야기 작문. 참고답안 「参考答案：（略）」 |
| 写作 第二部分 | 「第二部分」 (문항번호 없음) | 「示例：」 | 주제 제시문 보고 200자 이상 작문. 참고답안 「参考答案：（略）」 |

- 듣기 녹음 재생 횟수: 문서에 언급 없음 → 미확인.
- 문서는 듣기 대본을 「听力材料」/「录音文本」 등으로 라벨링하지 않고 「示例」 아래 대화문을 그대로 제시.
- 샘플 질문 문구 형식: 듣기는 「问：女的提醒男的怎么做？」처럼 「问：」 접두 + 의문문. 긴 대화·단문에서는 「11．关于“留白”，可以知道什么？」처럼 번호 + 의문문.

## 3. 샘플 문항 전문

출처: 발췌본 p.29–35 (전체본 p.29–35 동일). 한 줄 인용 제한 때문에 문장 단위로 추출해 재결합함. 원문의 구두점·띄어쓰기는 추출 결과를 따름.

### 3-1. 听力 第一部分（1-19 题）

**示例（1-10 题）：**

> 男：国庆节我想去参观国家博物馆，要提前买门票吗？
> 女：不用，那儿免费开放，但一定要先在线上预约。
> 问：女的提醒男的怎么做？

A 现场排队购票　B 自觉接受安检　C 进行电话预订　D 提前线上预约

「正确答案：D」

**示例（11-19 题）：**

> 11-12.
> 女：你照片里的内容太杂了。摄影也要讲究“留白”。
> 男：什么是“留白”？
> 女：“留白”源于国画创作，是指为了使画面更有诗意，故意留下空白。
> 男：你的意思是要留下更多想象的空间。
> 女：没错，带给人想象的同时还要让人关注到照片的主题。比如这张落日的照片，要是你能把更多的画面留给天空和大海，那么照片会更有意境，主题也更突出。
> 男：明白了，我还要再练练构图技巧。

11．关于“留白”，可以知道什么？
A 利于表达情感　B 能让人发挥想象　C 是一种写作方法　D 意味着大范围删改

12．女的觉得那张落日的照片怎么样？
A 色彩对比弱　B 主题不够突出　C 背景比较模糊　D 天空所占比例大

「正确答案：11．B 12．B」

### 3-2. 听力 第二部分（20-35 题）

**示例 22-24.**

> 苏洵少时不爱读书，只喜欢游山玩水，直到二十七岁才开始努力学习。因为自己读书晚，他深知年少读书的重要性，便教导两个儿子苏轼、苏辙从小读书。但苏洵多次劝说也没有效果，他决定改变教育孩子的方法，后来他想出了个好主意。苏洵每次看书时都故意躲到角落里去，而且只要两个孩子一靠近，他便赶紧把书藏起来。这激发了兄弟俩的好奇心：父亲为什么要背着他们看书？书里面到底有什么好玩儿的？于是他俩趁苏洵不在时，把他藏的书找出来，认真地读起来。慢慢地，两个孩子对书产生了浓厚的兴趣，开始广泛阅读，为日后成为著名文学家打下了基础。

22．苏洵年少时有什么爱好？
A 弹琴　B 游玩　C 写诗　D 练书法

23．苏洵的哪种做法起了作用？
A 把书藏起来　B 制定阅读规则　C 固定学习时间　D 让儿子大声读书

24．苏洵的儿子后来怎么样了？
A 总是躲起来　B 很信任父亲　C 发起了改革　D 成了文学家

「正确答案：22．B 23．A 24．D」

(샘플에는 지문 뒤의 「问：」 형식 질문 낭독 여부가 표시되지 않음. 22–24 문항 문구는 시험지 인쇄문인지 녹음 낭독문인지 미확인.)

### 3-3. 阅读 第一部分（36-45 题）

**示例：** (빈칸 42–45. 36–41은 미수록)

> 近年来，中国电动自行车年销量超过三千万辆，社会现有电动自行车数量接近三亿辆，几乎相当于每个家庭都有一辆电动自行车。为什么人们对电动自行车这么“情有独钟”？
> 首先是方便。 42 ，电动自行车在启动和停车时花费的时间最少。随着智能化程度的加深，电动自行车甚至不再需要使用钥匙，直接用手机开锁就行，再加上占地 43 小，车主也不再为找车位而发愁。
> 其次是用途 44 。电动自行车的使用体验好，适用于多种日常生活场景：上下班、接送孩子、外出买菜……也不用考取驾照，上了年纪的人也可以驾驶，能 45 多方面需求。

42．A 也有人反映　B 不用担心堵车　C 比起其他交通工具　D 电动自行车快速发展
43．A 场所　B 面积　C 地区　D 地面
44．A 实用　B 高档　C 有利　D 广泛
45．A 组合　B 实施　C 满足　D 达成

「正确答案：42．C 43．B 44．D 45．C」

(문단 나눔은 추출 텍스트 기준 추정. 42번처럼 절 단위 보기와 43–45처럼 단어 단위 보기가 한 지문에 혼재.)

### 3-4. 阅读 第二部分（46-55 题）

**示例：** 「51-55.」 (46–50은 미수록)

> A 因为家里穷，没钱吃饭，他每天晚上煮好一锅粥，等粥凉了结成块，再用刀把粥划成四块。一天两餐，早晨吃两块，晚上再吃两块。即使生活这样艰苦，也没有阻止他求学的决心。
>
> B 范仲淹小时候父亲就去世了，他与母亲相依为命。面对不幸的身世，他从不抱怨，而是选择了勤奋读书。
>
> C 范仲淹向他解释说：“您赠给我好的饭菜，我实在感激，但我平时吃粥习惯了，并没有觉得苦。现在我如果吃了这些东西，就会习惯好饭好菜，那将来就吃不下粥了。”
>
> D 范仲淹收下了饭菜，但是迟迟没有动筷子。过了几天，留守官的儿子再来看范仲淹时，发现自己送给他的饭菜竟然还在那里，都已经坏了。他觉得很奇怪，问道：“难道是饭菜不合口味吗？”
>
> E 范仲淹苦读的事情传开以后，当地一个留守官的儿子见他生活清苦，却依然不放弃学习，十分同情他，便从家里送来好菜好饭。

답안 기입란 원문: 「51． 52． 53． 54． 55．」
「正确答案：51．B 52．A 53．E 54．D 55．C → → → →」 (정답 순서 B→A→E→D→C)

### 3-5. 阅读 第三部分（56-70 题）

**示例：** 「63-66.」 (56–62, 67–70은 미수록)

> 1991 年，桑国亚只身一人来到中国留学。随着在中国的时间越来越长，桑国亚对茶的兴趣越来越浓，认识也越来越深刻。他说，中国的茶文化总让他感觉“学而知不足”。
>
> 为了进一步增进了解，桑国亚开始正式学习茶艺，他走遍了中国各地茶园。“在福建，每天晚饭后在家中泡上一壶铁观音，成为当地家庭生活的一部分；在广州，茶楼里的茶艺师傅摆弄着各式各样的茶具，表演着精彩的工夫茶；在成都，朋友邀请我去茶馆品尝竹叶青，让我第一次看到茶叶直直地立在水中。”桑国亚说，这些经历不仅让他收获了与茶相关的知识，还认识了很多热情好客的中国朋友。
>
> 如今，对茶的热爱让桑国亚开始向更多的人分享中国茶文化。他回国后在学校里教茶文化课，在他的课堂上，有人对茶的种类、饮茶方法等感兴趣；有人则因喝茶有益健康而渴望了解茶。
>
> 桑国亚发现，陷入烦恼时，泡一杯茶细细品味能让人忘记那些令人头疼的问题。“需要提神选绿茶，需要暖胃选红茶。”桑国亚希望通过自己的努力，把茶的趣味分享给更多的人。

(63번의 「画线部分」은 제1단락의 “学而知不足”로 추정. 텍스트 레이어에서 밑줄 위치는 확인 불가.)

63．第一段中画线部分的意思最可能是：
A 茶文化内容深厚　B 茶文化有不足之处　C 茶文化普及度不高　D 很欣赏现在的茶文化

64．桑国亚是如何学习茶艺的？
A 向名师请教　B 参观制茶工厂　C 浏览茶艺视频　D 接触各地茶园

65．桑国亚为了分享中国茶文化做了什么？
A 举办茶文化节　B 组织茶艺表演　C 研制茶叶新品种　D 担任茶文化课程老师

66．根据上文，下列哪项正确？
A 福建人习惯饭前泡茶　B 适当喝红茶可以提神　C 喝茶让桑国亚忘记烦恼　D 竹叶青是广州特有茶叶

「正确答案：63．A 64．D 65．D 66．C」

### 3-6. 写作 第一部分

표제: 「写作样题」 / 「第一部分」 / 「示例：」

> 请根据下面四张图，写一篇不少于 100 字的作文，写出发生在李明和伙伴们身上的故事。

- 그림 4장: PDF 텍스트 레이어에 이미지 설명·캡션·①②③④ 라벨 없음 → **그림 내용 미확인**. 등장인물은 지시문의 「李明和伙伴们」만 확인.
- 「参考答案：（略）」 (모범답안 생략). 채점기준 없음.

## 7. 미확인 항목 정리

- 听力·阅读 각 파트의 **시험지 지시문 원문** (문서에 없음)
- 듣기 녹음 **재생 횟수**, 문항 질문의 낭독/인쇄 여부
- 听力 第一部分 1–10·11–19 전 문항의 형식 통일 여부, 第二部分 20–35의 지문 수·지문당 문항 수
- 阅读 第二部分 46–50의 형식(51–55와 동일한지), 고정 첫 문단 여부
- 写作 第一部分 **4컷 그림의 내용**
- 写作 모범답안(「参考答案：（略）」), 채점 기준
- **总分·영역별 만점·合格线** (공식 미공개)
- 词汇量·汉字量의 공식 大纲 원문 수치 (大纲 PDF 접근 불가; 2차 자료는 5급 누적 3,600어)
- 口语 구조의 공식 문서 원문 (2차 자료 분석만 확보)
- 표지 「2026﹣07 实施」와 1차(2026-01-31)·2차(2026-09-20) 시행, 전면 시행(2026-12-13)의 관계
