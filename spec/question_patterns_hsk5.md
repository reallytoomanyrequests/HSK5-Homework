## 0. 자료 범위와 표기 규칙

- **직접 분석한 2.0 기출 4회분(공식 真题集, 듣기 스크립트 포함)**: H51001, H51003, H51005, H51219. 여기에 독해·쓰기만 분석한 H51328, 공식 样卷(NewHSK5-sample) 1부를 더함. 통계에서 "4회분"은 앞의 4개 시험지를 뜻한다(듣기 1부분 80문항, 2부분 40문항, 지문 21편, 독해 3부분 20지문·80문항).
- **3.0 공식 자료**: 汉考国际『新版HSK（1-6级）考试结构与样题示例』(2025.12 발표, 2026.7 시행 표기) 5급 부분. 샘플 문항이 각 파트에 1세트씩만 실려 있어 3.0의 분포 수치는 대부분 "추정"이다.
- **상업·해설 자료**: open-exam-prep(장별 해설, 모의문항은 자체 제작임을 명시), prepedu, eblcu, hsklord, italki, lcchineseschool, chinese-forums 등. 이들 자료의 수치는 출처를 밝히고, 자체 제작 문항은 패턴 설명에만 쓴다.
- 기출 문항의 대화·지문 본문은 옮겨 적지 않았다. 질문 문구(问：…)는 정형 표현이라 그대로 수록했고, 본문 인용은 15단어 이내 구절로 제한했다. 3.0 공식 样题의 지시문·질문·보기는 공식 샘플이므로 그대로 적었다.
- 수치 표기: 직접 센 값은 그대로, 자료에서 가져온 값은 출처 명시, 확인 못 한 값은 **(추정)**.

## A. 듣기 1부분 (대화)

### A-1. 형식 수치

**2.0 (1–20번, 4회분 80문항 직접 집계)**
- 턴 수: **80문항 전부 2턴**(남1·여1). 예외 없음.
- 첫 화자: **홀수 번호는 女 먼저, 짝수 번호는 男 먼저**로 4회분 모두 엄격히 교대. 새 세트를 만들 때도 교대 규칙을 지키면 자연스럽다.
- 길이: 대화 전체 30–80자. 분포는 H51003 32–78자(중앙값 약 44), H51001 30–50자, H51005 40–70자, H51219 40–70자. **권장 범위 40–60자, 한 턴 15–30자.**
- 질문은 3인칭(男的/女的/他们)으로 "问：…" 한 문장. 보기 4개(A–D).
- 재생 1회, 문항 간 간격 약 12–15초(open-exam-prep).

**3.0 (1–19번, 공식 样题)**
- 1–10번: 대화 1편에 1문항. 样题는 **4턴**(男→女→男→女). 예시(공식 样题 전문): 男「国庆节我想去参观国家博物馆，要提前买门票吗？」女「不用，那儿免费开放，但一定要先在线上预约。」男「具体怎么弄？」女「在手机上搜索"国家博物馆"小程序，点进去根据提示操作就行。」 问「女的提醒男的怎么做？」 보기 A 现场排队购票 B 自觉接受安检 C 进行电话预订 D 提前线上预约 (정답 D). 길이 약 75자.
- 11–19번: 대화 1편에 **2문항 이상**. 样题(11–12)는 **6턴**, 사진의 "留白"을 소재로 한 설명형 대화. 질문 「关于"留白"，可以知道什么？」/「女的觉得那张落日的照片怎么样？」
- (추정) 11–19 구간은 9문항이므로 2문항 대화 3편 + 3문항 대화 1편, 또는 2·2·2·3 같은 조합. 6턴 대화 길이는 150–200자로 추정.
- 3.0 대화는 2.0보다 "정보 전달형"(예약 방법, 용어 설명)이 늘었고 보기도 4자 동사구(现场排队购票)로 정형화되어 있다.

|---|---|---|
| 종합 세부(대화에서 알 수 있는 것) | 20% (16) | 根据对话，可以知道什么？ / 从对话中可以知道什么？ / 通过对话，可以知道什么？ / 关于女的，可以知道什么？ / 关于男的，下列哪项正确？ / 关于小王（公司·那份报告·张老师），可以知道什么？ / 根据对话，下列哪项正确？ |

핵심 시사점: 교재가 강조하는 "장소·직업·관계" 문제는 실제로는 한 회에 1–2문항뿐이다. 한 세트 20문항을 만들 때 권장 배합은 **종합세부 4 / 의도·태도 3 / 행동·제안 3 / 특정명사 3 / 이유 2–3 / 평가 2 / 장소·시간·관계·상태 각 0–1**.

open-exam-prep(상업 자료)은 "신분·관계 20–25%, 행동·의도 30–35%"라고 쓰지만 직접 집계와 다르다. 직접 집계를 우선한다.

### A-3. 보기 4개의 형식

- 종합세부·관점형: 짧은 절(5–9자) 4개, 주어 생략형. 예: "打算换工作 / 对价格不满意 / 刚搬了家 / 没买到票" 형태.
- 장소·직업·관계: 2–4자 명사. 예 유형: 银行 / 机场 / 图书馆 / 医院, 导游 / 记者 / 教练 / 律师, 夫妻 / 同事 / 师生 / 邻居.
- 이유·행동: 동사구 4–8자. 3.0 样题의 보기는 **6자 동사구**(现场排队购票 / 自觉接受安检 / 进行电话预订 / 提前线上预约)로 길이와 구조를 맞춘다.
- 평가·태도: 형용사·태도 명사 2–4자(满意 / 怀疑 / 无所谓 / 失望).
- 보기 네 개는 길이·품사·구조를 통일한다. 한 보기만 길거나 품사가 다르면 안 된다.

### A-4. 오답 설계 방식 (기출 관찰 + open-exam-prep·prepedu)

1. **들린 단어 그대로 쓰기(关键词陷阱)**: 대화에 나온 명사를 그대로 넣되 관계를 바꾼다. 정답은 보통 대화 어휘를 **바꿔 말한 것**(동의어·상위어·격식어)이다. 예: 대화 "我把钥匙落在出租车上了" → 정답 "东西丢了", 오답 "要坐出租车".
2. **주체 바꾸기**: 남자의 계획을 여자의 것으로.
3. **부정·전환 뒤집기**: 첫 턴의 제안이 둘째 턴에서 거절·수정되는데, 첫 제안을 정답처럼 배치.
4. **숫자·시간 변형**: 대화에 두 개의 시간이 나오면 바뀐 쪽이 정답, 원래 쪽이 오답.
5. **반어·관용 표현 직역**: "这还用说吗" → 오답 "不想说", 정답 "当然". "那怎么好意思" 류의 완곡 표현도 자주 쓰인다.
6. **완전 무관 보기 1개**: 네 보기 중 하나는 분명히 틀린 것으로 두어 난이도를 조절.

### A-5. 빈출 장면·토픽 (4회분 80대화 라벨 집계)

- 직장·업무(회의 연기, 보고서 기한, 면접·응모, 사직, 출장, 방안 평가, 사회자 선정, 녹음 재녹음): 약 25%
- 건강·병원(퇴원, 알레르기, 불면, 멀미약, 다리 부상, 휴식 권유, 헬스장): 약 12%
- 소비·외식·서비스(계산, 옷 평가, 식당 식기 요청, 냉장고, 택배, 택시): 약 12%
- 가정·주거·이사(이사 도움, 인테리어, 가구 조립, 아이 등교): 약 10%
- 학업·논문(편집자 수정 요구, 논문 조언, 강연 놓침): 약 8%
- 취미·문화(사진, 장기, 탁구·테니스, 드라마, 영화 협업, 비둘기 먹이): 약 10%
- 여행·교통(여행 기간, 공항, 베이징 인상, 등산 중 휴식): 약 8%
- 기기·기술(충전기 고장, 소프트웨어 설치, 이메일 비밀번호): 약 6%
- 금융·기타(주식 위험, 결과 발표, 성취와 노력): 약 9%

3.0 样题 장면: 박물관 예약(모바일 小程序), 사진 구도(留白). 3.0은 **디지털 생활·문화 상식 설명** 장면을 더 넣는 것이 좋다.

## B. 듣기 2부분 (긴 대화·단문)

### B-1. 2.0 21–30번 (4–5턴 대화, 1문항) — 4회분 40문항 집계
- 턴 수: 4턴 34문항(85%), 5턴 6문항(15%). 첫 화자는 1부분과 같이 홀짝 교대(21 女, 22 男…).
- 길이: 60–150자, **전형 80–100자**. 재생 후 간격 약 13–15초.
- 질문 유형: 关于X，可以知道什么/下列哪项正确 (30%) ≫ 특정 정보(什么时候公布·多少字·哪个部门·什么业务) (25%) > 장소·직업(他们最可能在哪儿？/女的最可能在哪儿工作？) (10%) ≈ 의도(男的是什么意思？) (10%) ≈ 이유(女的为什么要早起？) (10%) > 행동·화제(他们在谈论什么？/他们打算怎么办？/男的正在咨询什么？) (15%).
- 전개 패턴: 첫 턴 제안·질문 → 둘째 턴 정보 제공 → 셋째 턴 추가 질문·조건 → 넷째 턴 결론. open-exam-prep은 "첫 제안이 수정·거절되는 비율 70% 이상"이라 쓰나 출처가 없어 **(추정)**으로 둔다. 전환 표지: 其实 / 不过 / 要不 / 那 / 既然这样.

### B-2. 단문 (2.0 31–45번, 3.0 20–35번)

**글 종류 비율 (2.0 4회분 지문 21편 직접 분류)**
- 이야기·우화·일화(교훈형 포함): 12편 = **57%** (예: 농부와 토끼, 노인과 말, 아판티, 당나귀와 소금, 쑤쉰·판중옌 같은 역사 일화, 어머니와 아들, 유머 소화)
- 설명문(문화·과학·조사 보고·지역 소개·반려동물 효용·전동 쓰레기통 정책): 6편 = **29%**
- 논설문(작은 일과 큰 일, 습관, 아이에게 문 열게 하기): 3편 = **14%**
- 대화형(인터뷰·긴 대화): 21편 중 2편(H51001에만). **(추정)** 회당 0–2편.
- 3.0 样题(22–24): 약 300자 **역사 일화(쑤쉰이 책을 숨겨 아들들을 독서로 이끈 이야기)**, 3문항. 3.0도 "역사 인물 일화 → 교훈" 패턴이 유지된다.

**길이**: 150–300자(2.0 실측 150–290, 전형 200–260). 3.0 样题 약 300자. 음성 분당 220–250자(open-exam-prep) → 40–80초.

**지문당 문항 수**: 2.0은 2–4문항(3문항이 70% 이상, 2문항 지문은 150–200자 짧은 것). 3.0 20–35는 16문항 → **(추정)** 3문항 지문 4편 + 2문항 지문 2편, 또는 3·3·3·3·2·2.

**질문 유형 (2.0 지문 질문 63개 집계)**
- 세부 사실(为什么…? / …做了什么? / …怎么样了? / …是哪天? / 多少人…?): 약 60%
- 인물·사물 종합(关于X，可以知道什么？/ 关于X，下列哪项正确？): 약 15%
- 주제·교훈(这段话主要谈什么？/ 这段话主要讲的是什么？/ 这个故事主要想告诉我们什么？/ 这段话想告诉我们什么道理？): 약 15%, **이야기·논설 지문의 마지막 문항은 거의 항상 이 유형**
- 어휘·표현 의미("七夕"的"夕"是什么意思？/ "人杰地灵"主要是什么意思？/ 下列哪个词可以用来形容江南？): 약 5%
- 화자 의도(太太是什么意思？): 약 5%
- 3.0 样题 질문: 苏洵年少时有什么爱好？ / 苏洵的哪种做法起了作用？ / 苏洵的儿子后来怎么样了？ (세부→핵심 행위→결과, 시간순)

**전형적 첫 문장·결말 패턴**
- 이야기형 첫 문장: 「从前，有一个…」「一天，…」「一位年轻人…」「有个农民…」; 역사형: 「宋代有个叫…的人」「北宋文学家…小时候…」.
- 이야기형 결말: 「这个故事告诉我们，…」「其实，…往往…」「可见，…」「人生也是如此，…」. 교훈은 추상 명제로("心态往往决定成败" 류), 줄거리 반복이 아니다.
- 설명형 첫 문장: 「…是指…」「在中国，…」「有一项调查显示，…」「心理学上有一个…效应」; 결말: 「因此，…」「专家建议，…」「由此可见，…」.
- 논설형: 첫 문장에 통념 제시 → 「其实」「然而」로 전환 → 「所以」로 주장.

### B-3. 출제 시 배합 권장 (3.0 기준 하루 세트용)
- 이야기·일화 55% / 설명 30% / 논설 15%. 지문 200–300자. 각 지문 3문항: 세부 2 + 주제(또는 종합) 1. 이야기형은 마지막 문항을 道理 질문으로.

- 종합: 「关于X，可以知道什么？」「关于X，下列哪项正确？」「根据上文，可以知道：」「下列哪项说法正确？」
- 어휘: 「第N段中画线词语最可能是什么意思？」「与第N段中画线词语意思相近的是：」「可以替换第N段中"X"的词语是：」「"X"在文中的意思是：」
- 주제: 「上文主要想告诉我们：」「上文主要讲的是：」「这段话主要谈的是什么？」「这个故事主要告诉我们什么道理？」「最后一段主要想告诉我们：」
- 제목: 「最适合做上文标题的是：」(보기는 4–8자 명사구나 짧은 명제: 「成功的秘诀」「换一个角度」「别背着船走路」류)
- 의도·태도: 「作者对X持什么态度？」「作者举X的例子，是为了说明：」

### E-5. 오답 설계
- 본문 어구 복사 + 주체·결과 바꾸기(가장 많음). 정답은 본문의 바꿔 말하기.
- 정도·양태 조작: 「可能」→「一定」, 「有些」→「所有」, 절대어(只能/彻底/从来) 추가.
- 시간 어긋남: 과거 사건을 현재·미래로.
- 제목 오답: 너무 넓음 / 너무 좁음(한 단락만) / 교훈 방향 비틀기.
- 어휘 의미 오답: 글자 그대로의 뜻(兜风→"바람을 쐬다"가 아니라 "드라이브")을 넣어 문맥 독해를 요구.

### F-1. 형식 비교

| 지시문 | 请结合下列词语（要全部使用，顺序不分先后），写一篇80字左右的短文。 | 请结合这张图片写一篇80字左右的短文。 | 请根据下面四张图，写一篇不少于100字的作文，写出发生在李明和伙伴们身上的故事。(样题) | 尝试可能会成功，也可能会失败，但不去试一试就永远不会成功。请写一篇不少于200字的作文，分享你曾经做过的一次尝试，以及你尝试后的感受。(样题) |

### F-2. 2.0 99번 단어 세트 패턴 (기출·样卷 수집 7세트)
元旦·放松·礼物·表演·善良(样卷) / 成立·扩大·信心·服务·谦虚 / 结账·干脆·感谢·临时·海鲜 / 虚心·效率·学期·鼓励·羡慕 / 婚礼·打扮·兴奋·费用·气氛 / 语言·困难·灰心·鼓励·进步 / 博物馆·保存·讲解员·丰富·值得
- 구성 공식: **명사 2 + 동사 1–2 + 형용사·부사 1–2**, 다섯 단어가 한 장면(결혼식, 박물관 견학, 식당 계산, 회사 창립, 외국어 학습)으로 자연스럽게 묶이게 고른다. 한 단어는 추상어(信心·气氛·效率), 한 단어는 감정어(兴奋·灰心·羡慕)를 넣는 경향.
- 모범 답안 구조(4–6문장): ①배경·인물(上个月/作为…/为了…) → ②사건·행동(단어 3개 소비, 不仅…而且… / 把 문) → ③결과·느낌(단어 1–2개, 让我…/我觉得…).

### F-3. 2.0 100번 그림 패턴
- 그림: 인물 1–2명의 일상 장면. 응시자 보고·해설서 집계 주제: 계약서 서명(열쇠·임대), 커피를 쏟은 회사원, 운동(달리기·요가), 요리, 병문안, 면접, 등산·여행, 쓰레기 분리, 가족 식사, 노인 돕기, 컴퓨터 앞 야근, 쇼핑, 사진 촬영, 식물 가꾸기.
- 구조(3–4문장): ①장면 묘사 「图片上/画面中，一个…正在…」(30자) → ②상황 설명·추측 「看起来/也许/因为…所以…」(25자) → ③감상·교훈 「我觉得…/这说明…/只要…就…」(30자).

### F-4. 3.0 1부분 (그림 4장, ≥100자)
- 样题 지시: 인물 이름(李明)과 "伙伴们"이 주어진다. 네 컷은 시간순 서사(기→승→전→결)로, 답안은 **시간어 + 인물 행동 + 결과 + 한 줄 느낌**.
- 권장 틀(120–140자): ①「一天/周末，李明和伙伴们…」(1컷) → ②「他们先…，然后…」(2컷) → ③「没想到/这时，…」(3컷, 문제·전환) → ④「最后，…。大家都…」(4컷) → ⑤「通过这件事，…」(한 문장).
- 그림 주제 후보(2.0 100번 주제 + 3.0 任务 참조): 등산 중 길 잃음, 비 오는 날 우산 나눔, 공원 쓰레기 줍기, 노인 길 안내, 팀 과제·발표 준비, 자전거 고장 수리, 캠핑·바비큐, 길 잃은 강아지 돌려주기, 지하철 분실물, 요리 실패와 성공, 운동회, 자원봉사.

### F-5. 3.0 2부분 (命题作文, ≥200자)
- 题干 구조: **명제(격언형 한두 문장) + 「请写一篇不少于200字的作文，分享/谈谈/说说…」+ 요구 2개(경험 + 느낌/의견)**.
- 권장 구조(220–260자): 서론(명제 받아 쓰기·입장, 40–50자) → 본론1(경험·사례, 90–110자) → 본론2(이유·영향, 50–60자) → 결론(총괄·다짐, 30–40자).
- 표지어: 서론 「俗话说/人们常说…」「在我看来」「我也有过这样的经历」; 본론 「记得…的时候」「首先…其次…」「一方面…另一方面…」「不仅…而且…」; 전환 「然而」「不过」; 결론 「总之」「因此」「正如…所说」「我相信只要…就…」.

### F-6. 자주 나오는 주제 목록 (35개; 2.0 기출 단어 세트·그림 주제, 3.0 样题, prepedu·open-exam-prep·lcchineseschool 주제 목록, 新版大纲 話題 참조)
1. 한 번의 도전·시도와 그 느낌(3.0 样题) 2. 실패에서 배운 것 3. 끈기·포기하지 않기 4. 습관 기르기(독서·운동·조기 기상) 5. 시간 관리와 효율 6. 나의 꿈·진로 선택 7. 외국어 학습 경험과 어려움 8. 잊지 못할 선생님·멘토 9. 가족과의 추억·부모의 사랑 10. 우정과 신뢰 11. 결혼식·명절 등 행사 참석 12. 여행에서 얻은 것 13. 고향 소개·도시와 농촌 14. 건강한 생활(수면·식습관·운동) 15. 스트레스 해소법 16. 직장 생활·첫 출근·팀워크 17. 면접 경험 18. 소비 습관·충동구매·절약 19. 인터넷·스마트폰 의존 20. 온라인 학습 vs 교실 학습 21. 인공지능·과학기술이 생활에 미친 변화 22. 환경 보호·쓰레기 분리·저탄소 생활 23. 자원봉사·남을 도운 경험 24. 전통문화 체험(차·서예·명절 음식) 25. 독서가 준 영향·좋아하는 책 26. 반려동물 27. 자신감과 겸손 28. 감사했던 일(감사 편지형) 29. 선택의 갈림길(안정 vs 도전) 30. 혼자 사는 삶·독립 31. 교통·이사·새 환경 적응 32. 취미(사진·음악·운동)의 의미 33. 성공의 정의 34. 세대 차이·부모와의 소통 35. 박물관·전시 관람 경험

## G. 말하기 (3.0 5급 口语)

공식 3.0 口语 样题는 이번 조사에서 열람하지 못했다(chinesetest.cn 직접 접근 차단, 미러 미발견). 아래 구성은 eblcu(단일 출처) + 구판 HSKK 中级·高级 공식 샘플을 조합한 것이며 수치는 **추정**이다.

### G-1. 구성 (eblcu)
- 1부분 **听后复述** 2문항(구판 高级은 3문항). 2부분 **看图说话** (구판 高级의 朗读 대체). 3부분 **回答问题** 2문항(구판과 동일). 시험 시간 준비 포함 약 23분(studycli, syllabus 문서 참조).
- 이 세션의 과제 설명에는 2부분이 "그림 3장"으로 적혀 있으나 eblcu는 "a picture"라고만 쓴다. 그림 매수는 **미확인**. 교재(해커스)의 기술을 우선 확인할 것.

### G-2. 1부분 复述 지문과 답변 틀
- 지문 길이 **(추정)** 150–250자, 1회 청취, 준비 시간 후 2분 내외 복술. 구판 HSKK 高级 복술 지문이 이 범위.
- 지문 유형: 듣기 2부분 단문과 같은 **이야기·일화(교훈 결말)** 또는 짧은 설명. 복술용 지문은 인물 2명 이하, 사건 3단계(상황→전환→결과), 숫자·고유명사 최소화.
- 모범 답변 틀(100–150자): 「这段话讲的是…的故事。」→ 「一开始/有一天，…」→ 「后来/没想到，…」→ 「最后，…」→ 「这个故事告诉我们，…」. 핵심 동사·접속사(于是·结果·因此)를 지문 그대로 살리고, 세부 묘사는 생략한다.

### G-3. 2부분 看图说话
- 구판 中级 看图说话는 그림 1장당 준비 후 2분 발화. 3.0 5급도 **(추정)** 2분.
- 답변 틀(150자 내외): 장면 소개(图片上/这是在…) → 인물·행동(一个…正在…，旁边…) → 사건 추측·전개(可能是因为…/接下来…) → 감상·의견(我觉得…/这让我想到…).
- 그림 주제는 F-4의 후보 목록과 공유 가능.

### G-4. 3부분 回答问题 전형 질문과 답변 구조
- 구판 공식 샘플 질문: 「你喜欢和什么样的人交朋友？为什么？」「你对减肥是什么态度？为什么？」. 구조는 **「你…？为什么？」** 두 문장형.
- 3.0용 전형 질문 틀(新版大纲 話題 기준, 작성자 구성): 「你认为…重要吗？为什么？」「你更喜欢…还是…？请说明理由。」「谈谈你对…的看法。」「如果…，你会怎么做？」「请介绍一个你…的经历。」
- 예시 질문 20개: 你喜欢什么样的工作环境？ / 你认为大学生应该打工吗？ / 网络购物有哪些好处和坏处？ / 你怎么看待手机对生活的影响？ / 你觉得学外语最难的是什么？ / 你更愿意住在大城市还是小城市？ / 你怎样缓解压力？ / 你认为成功最重要的因素是什么？ / 你对养宠物有什么看法？ / 你认为应该如何保护环境？ / 你喜欢一个人旅行还是和朋友一起？ / 你怎么看待"活到老，学到老"？ / 你觉得朋友之间最重要的是什么？ / 你理想的周末是怎样的？ / 你怎么看网络学习？ / 你认为父母应该怎样教育孩子？ / 你对传统节日有什么看法？ / 你会为了兴趣放弃高薪工作吗？ / 你认为城市交通问题怎么解决？ / 你怎么看待人工智能？
- 답변 구조(2분, 180–220자): 입장 한 문장(我认为/在我看来) → 이유 2개(首先…其次… / 一方面…另一方面…) → 예시 또는 경험 1개(比如/拿我自己来说) → 마무리(总之/所以我觉得).

### H-1. 빈출 토픽 상위 20 (듣기 대화 80편·단문 21편·독해 지문 45편·쓰기 세트 집계, 3.0 样题 반영)

### H-2. 5급다운 표현 — 문법 포인트
- **把 문**(把钥匙落在…/把书藏起来/把方案改一下): 듣기 대화·쓰기에서 회당 다수. 결과보어·방향보어와 결합.
- **被/让/叫 피동**(被其他读者预约了/被录取/被淋湿): 독해·듣기에서 빈출.
- **연동문·겸어문**(去银行办业务 / 请他帮忙 / 让孩子自己开门).
- **보어**: 결과(听懂·写完·修好), 방향(拿出来·坚持下去·走进去), 가능(来得及·看不清·受不了), 정도(忙得不可开交·累得要命).
- **비교·강조**: 比…多了 / 不如 / 越来越 / 连…都… / 是…的 / 再…也… / 一…就….
- **어기부사**(태도 문제의 열쇠): 倒 / 未必 / 难怪·怪不得 / 究竟·到底 / 索性 / 简直 / 反正 / 居然 / 竟然 / 毕竟 / 不妨 / 恐怕.
- **반어·완곡**: 这还用说吗 / 你以为那么容易啊 / 何必呢 / 谁知道呢 / 那怎么好意思 / 看情况吧·到时再说 / 恐怕有点儿… / 改天我请客.
- **격식어 전환**(정답 보기에 자주 쓰임): 委婉谢绝, 表示感谢, 持怀疑态度, 无法接受, 感到遗憾, 不以为然, 心不在焉.

### H-3. 성어·관용구 빈도
- 공식 2.0 5급 어휘표의 4자어는 名胜古迹·讨价还价 정도이며, 시험 본문에는 그 밖의 성어가 **지문당 0–2개** 등장한다(독해 3부분 어휘 의미 문항의 단골: 妄自菲薄·心灰意冷·始料未及·下了逐客令·人杰地灵·兜风).
- 출제 시 권장 빈도: 듣기 대화 1부분은 20문항 중 2–3개에 관용구 1개씩(태도 문제용), 단문·독해 지문은 300자당 1개, 쓰기 모범답안은 1–2개.
- 자주 쓰이는 성어 목록: 坚持不懈 / 半途而废 / 全力以赴 / 废寝忘食 / 熟能生巧 / 实事求是 / 随机应变 / 胸有成竹 / 恍然大悟 / 莫名其妙 / 迫不及待 / 理所当然 / 恋恋不舍 / 显而易见 / 焕然一新 / 潜移默化 / 斤斤计较 / 络绎不绝 / 一举两得 / 四面八方 / 自言自语 / 乱七八糟 / 千方百计 / 不知不觉 / 无能为力 / 与众不同 / 日新月异 / 一模一样.

## I. 하루 세트 설계 체크리스트 (3.0 기준, 숙제방 앱용)

- 듣기 1부분: 4턴 대화 3편(1문항) + 6턴 대화 1편(2문항). 대화 60–90자 / 150–200자. 남녀 교대, 첫 화자 번갈아. 질문 유형은 A-2 배합. 보기 4개는 같은 길이·품사.
- 듣기 2부분: 단문 1–2편(200–300자, 3문항: 세부 2 + 주제 1). 이야기형이면 마지막 문장은 교훈.
- 독해 1부분: 지문 1편(200–250자) 3–4칸, 절 빈칸 1개 포함, 보기는 같은 품사·같은 음절.
- 독해 2부분: 5문단 배열 1세트(300–400자). 첫 문단에 고유명사 전체, 중간 문단은 지시사·시간어로 연결.
- 독해 3부분: 지문 1편(400–500자) 4문항(세부 2 + 어휘/종합 1 + 주제/제목 1).
- 쓰기: 4컷 서사 ≥100자(인물명 제시) 또는 命题 ≥200자(명제 + 경험 + 느낌) 중 하루 1개. 모범답안에 F-5 표지어 포함.
- 말하기: 복술 지문 1편(150–250자, 모범 복술 100–150자) + 그림 설명 1 + 질문 1(「你…？为什么？」형, 모범답변 180–220자).
